# Small Hours — prototype audio

Original spoken-word music made for this website prototype on 20 November 2026.
Original eight-line text, synthesizer arrangement and recording generated by
`scripts/generate-demo-audio.py`; no third-party song, samples or cloned voice.
The second verse repeats the first. This is deliberately a replaceable test track,
not a proposed final music selection. MP3, mono 22.05 kHz, approximately 68 seconds.

Speech is synthesized with eSpeak NG 1.52.0's stock en-us voice. Its GPL license
covers the software; output is covered only when its content constitutes a covered
work: https://espeak.sourceforge.net/license.html . No eSpeak program/data is shipped.
The original text and procedural music may be used, modified and distributed with
this website demo, including commercial use. No external recording clearance is
needed. This is a provenance record, not a claim that the owner selected this music.

The generator trims leading speech silence and places each voice onset at the
matching cue timestamp. `small-hours.lrc` and `src/content/demo-cues.json` are generated
from the same cue list. Instrumental intro 0–2s; voice onsets every 4s from 2–62s;
outro 66–68s. Line-level synchronization, not word highlighting.

Rebuild: install espeak-ng and ffmpeg; create a Python venv with numpy, then run
`scripts/generate-demo-audio.py` with that venv's Python.
