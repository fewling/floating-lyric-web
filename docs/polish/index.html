Motion alternatives

Two browser prototypes, with real audio-driven line changes. The larger alternative uses the native source’s 48px maximum / 300ms duration; it is not Android footage. The selected short settle travels 8px in 160ms. Both keep text fully opaque.

48px / 300ms alternative

8px / 160ms recommendation

At 60ms, the measured displacement was approximately 19px versus 2.5px. Short settling makes less of the reading interval move. Seeking, dragging and reduced-motion use immediate updates. This measurement does not establish a human reading-speed advantage.

Surface character — still your decision

All three use the refined controls and the same paused cue over the same privacy-page content. The provisional default retains the existing mint palette at 96% opacity and adds an 8px backdrop softening. No new appearance options were added to the product.
